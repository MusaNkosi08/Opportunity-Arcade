# User Stories

1. As a young South African job seeker, I want to search opportunities by keyword so that I can quickly find relevant quests.
   - Acceptance: title, organisation and description are searchable.

2. As a student, I want to filter opportunities by category so that I can focus on bursaries, courses or internships.
   - Acceptance: multiple category filters can be active together.

3. As a player, I want to see deadlines and countdowns so that I can prioritise urgent opportunities.
   - Acceptance: each card shows a deadline status.

4. As a user, I want to save opportunities so that I can return to them later.
   - Acceptance: saved records persist in localStorage.

5. As a user, I want a checklist for applications so that I can prepare before applying.
   - Acceptance: checklist ticks persist for the selected opportunity.

6. As a keyboard user, I want visible focus states and logical navigation so that I can use the site without a mouse.
   - Acceptance: interactive controls are keyboard reachable and focus is visible.

7. As a cautious applicant, I want scam warnings and demo labels so that I understand that information must be verified.
   - Acceptance: firewall warnings appear on key pages and records are labelled as demonstration data.
