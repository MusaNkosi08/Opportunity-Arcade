# OPPORTUNITY ARCADE

**Insert coin. Level up your future.**

Opportunity Arcade is a retro-futuristic youth opportunities platform designed for young South Africans to find **jobs, learnerships, internships, bursaries, courses, and career events**.

The platform turns finding opportunities into an arcade-style experience. Users can search for opportunities as **quests**, use filters as **difficulty settings**, save opportunities to their **inventory**, and track deadlines using **arcade countdowns**.

The website is built using **HTML5, CSS3 and Vanilla JavaScript**, with a JSON dataset for the opportunity information. It is responsive, accessible and designed to work across desktop and mobile devices.

> **Note:** The opportunities included are fictional demonstration data and should not be treated as real vacancies or application opportunities.
